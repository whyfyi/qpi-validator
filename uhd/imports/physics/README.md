# Physics TruthBomb v1 Imports (Local Only)

Place the physics PDF here for local validation, but do NOT commit the PDF.

- PDFs live here as symlinks or local copies, but are NOT committed.
- Recommended: create a symlink to wherever the PDF actually lives on your system.
- Expected filename: `Halliday_Cheatsheet.pdf`

Example (symlink):

```bash
ln -s "/path/to/Halliday_Cheatsheet.pdf" uhd/imports/physics/Halliday_Cheatsheet.pdf
```

This repository only tracks this README in the `physics/` imports folder; all other files in this folder are ignored by .gitignore.
