# WhyFYI OS Domain Map v1 (Interpretive Layer)

This document defines an interpretive semantic layer used by the WhyFYI OS for tagging and simulation contexts. It is NOT a claim about physical reality; it is a model framing applied to system tags, narratives, and sandboxed simulations.

Mappings (interpretive)
- Light → information / truth
- Time → consciousness
- Gravity → emotion
- Space → womb / creation

Usage guidance
- Treat the above as metaphorical/domain semantics to guide categorization, synthesis, and exploratory simulations.
- Do not read these mappings as assertions about empirical physics. They exist solely to provide a consistent internal ontology for system tags (e.g., QGL, QGG) and scenario modeling.
- When communicating outputs that leverage this layer, include disclaimers that the mapping is interpretive and for modeling purposes only.

Versioning
- v1 provides baseline semantics for Light, Time, Gravity, and Space. Future versions may expand with additional domain anchors or refine definitions to improve alignment across rulesets.
