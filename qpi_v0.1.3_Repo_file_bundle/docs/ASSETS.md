# QPI Visual + Paper Assets

This folder contains the reference visuals and paper drafts that document the QPI color-sieve / lattice framing.

## What you should expect (high-level)

- **qpi_spiral_twinprime_v3.6.png**: a tiled, color-coded grid that repeats mod 9, intended to visualize residue-class structure and “midpoint” placements.
- **9_wide_Helix.png**: a 9-wide column layout (mod 9) shown as a “helix” mapping (a visual reshaping of the same residue grid).
- **Mod_9_Double_Helix_DNA_Flow.png**: a plot that presents two strands (logic/empathy framing) over a helical geometry; this is a visualization aid, not a standalone proof.
