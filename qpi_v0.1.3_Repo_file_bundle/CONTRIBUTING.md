# Contributing (Receipts-first)

If you submit changes, include:
1) what you changed,
2) how you verified it (commands + output),
3) the new/updated receipt files in `results/`,
4) updated `results/checksums.txt` (recomputed).

No claim should be upgraded from “Conjecture” to “Theorem” without either:
- a formal proof script (Lean/Coq) or
- a peer-reviewed publication.
